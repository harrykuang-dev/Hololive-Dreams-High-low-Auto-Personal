# v1.1.4 — Unicode Path Compatibility

## English

- Fixed button template loading when the program is installed in a folder whose path contains Chinese or other non-ASCII characters.

Download **HololiveDreamsHighLowAuto.exe**. Stop the program before replacing the EXE. Records and preferences remain in `%LOCALAPPDATA%\HololiveDreamsHighLowAuto\`.

## 繁體中文

- 修正程式放在含中文或其他非 ASCII 字元的路徑時，無法讀取按鈕模板的問題。

下載 **HololiveDreamsHighLowAuto.exe**。替換 EXE 前請先關閉程式，既有記錄和設定會保留在 `%LOCALAPPDATA%\HololiveDreamsHighLowAuto\`。
