# v1.1.3 — Game Window Restore Fix

## English

- Fixed an issue where minimizing the game during High & Low could leave only the title bar visible. The program pauses capture while the game is minimized and resumes when you restore the game window.

Download **HololiveDreamsHighLowAuto.exe**. Before upgrading, stop the program and replace the EXE. Existing records and preferences in `%LOCALAPPDATA%\HololiveDreamsHighLowAuto\` are preserved.

## 繁體中文

- 修正比大小執行期間，遊戲最小化後可能只剩標題列的問題。遊戲最小化時會暫停擷取，手動切回遊戲後會繼續。

下載 **HololiveDreamsHighLowAuto.exe**。升級前停止程式並替換 EXE，既有記錄與設定會保留在 `%LOCALAPPDATA%\HololiveDreamsHighLowAuto\`。
